# Tableau-projects-Data-Visualisation
Built two interactive Tableau dashboards from scratch:

1. Global Data Science Job Market Analysis — visualised salary distributions by role, country, and experience level; mapped demand shifts for skills like Python, SQL, and ML across 2022–2024 hiring data.

2. IPL Performance Dashboard — analysed team and player performance trends across seasons, including win rates, batting averages, and venue-based insights.
